============================================================
  学习通助手（CDP 版）  使用说明
============================================================

一句话：它帮你把视频放完、把章节翻过去、把测验里 AI 给的
答案填进页面。它不会替你交卷。


------------------------------------------------------------
  零、先把边界说清楚
------------------------------------------------------------

会做的三件事：
  1. 放视频（不动倍速 —— 平台有 1 秒一次的风控，改倍速会被打回 1x）
     想更快可以不老实播：主菜单按 8 打开「伪心跳 60 倍速」。
     它不是把播放器调快（那条路被平台掐死了），而是替播放器把进度报上去。
     默认关着，细节见 学习通-CDP\原理说明.txt 第十节。
  2. 翻章节（点「下一节」，遇到拦路弹窗会自己处理）
     顺带把「文档/PDF」类任务滚到底
  3. 开测验后：读题 → 问 AI → 把答案填进页面 → 点「暂时保存」

不会做的一件事：
  点「提交」。这一条写死在代码里，不是设置项，改不掉。
  程序里凡是文字含「提交 / 交卷」、或者 class 里带 btnSubmit、
  或者 onclick 里带 submit 的按钮，一律拒绝点击。
  「暂时保存」是 noSubmit()，只是存草稿，不算交卷。

  后果要提前知道：**因为不提交，任务点在平台上不会变成"已完成"。**
  你会看到日志里视频播完了、题也填进去了，可课程目录里那一章
  还是未完成状态。这是正常的，不是坏了 —— 你自己检查答案、
  点一次提交，任务点立刻就清了。

为什么要这么卡：模型给的答案没有经过验证，交不交得你自己判断。
程序负责省掉打字，不负责替你下决定。

另外它不会动你的电源设置 —— 只在运行期间申请一个「别睡觉」，
屏幕该息还是息；屏保、锁屏、休眠这些设置它一个都不碰。


------------------------------------------------------------
  一、装之前要有什么
------------------------------------------------------------

  1. Windows 10 / 11
  2. Microsoft Edge（装在默认位置）。不能用 Chrome 顶上。
  3. 一个 DeepSeek API key（只在你要用「问 AI」时才需要）
       去 https://platform.deepseek.com/ 注册 → API keys → 新建。
       要保证账户里有余额，没钱会返回 402。

**不需要装 Node.js。** 分发包里已经带了一份（node\node.exe），
控制台和驱动器都会优先用它。不需要装 npm 包，也不需要 python。

  如果你拿到的是「精简版」（文件只有几百 KB 的那种），那里面
  没有带 Node，需要自己去 https://nodejs.org/ 下 LTS 版装一次
  安装后重新打开控制台；控制台会实际检查 fetch、WebSocket 和
  AbortController 是否可用。只看到 node -v 的版本号还不足以确认兼容。
  缺少运行所需的功能时会明确提示，不再等到启动驱动器后才报错。


------------------------------------------------------------
  二、三步开始
------------------------------------------------------------

第一步  解压
  把压缩包整个解压到任意目录（路径里最好别有大段中文和空格，
  比如 D:\xtzs\ 就挺好）。
  注意：现在包里有个 90 MB 的 node.exe，解压后文件夹会比较大。

第二步  填 key
  双击「学习通-CDP」里的  控制台.cmd
  → 按 4  （答题助手设置）
  → 按 4  （输入 / 更换 API key）
  → 粘贴，回车
  它会顺便问你要不要测一下，选是。

第三步  跑
  回主菜单 → 按 1 开始。

  第一次跑的时候，它会关掉当前所有 Edge 窗口，用一个**独立的
  配置目录**重新打开。那个窗口里你要自己登录一次学习通
  （手机号 + 密码），之后就一直记住了。

然后就不用管了。想看进度就再按一次 3（会另开一个窗口，一直刷新）。
要停就按 2。


------------------------------------------------------------
  三、控制台每个数字是什么意思
------------------------------------------------------------

主菜单
  1   开始 / 继续    没有浏览器就自己开一个；已经在跑就不重复启动
  2   停止            停驱动器，并关掉「自愈外套」（见第四节第 5 条）
  3   看实时进度      另开窗口盯着 运行日志.txt
  4   答题助手设置    ← 模式、key、模型都在这
  5   解码乱码        把 章节测验记录.txt 里被字体加密的题目翻成真字
  6   环境自检        查端口 / node / API key
  7   打开所在文件夹
  8   伪心跳 60 倍速    不碰播放器倍速，改为替它把进度报上去（默认关）
  0   退出

主菜单里的 8 是「伪心跳 60 倍速」，默认关。打开后：
  每一章仍会起播一下 —— 因为伪造之前得先从播放器自己的第一条真实上报里
  抄到「往哪报、带什么字段、令牌长什么样」，这三样凭空造不出来；
  然后由程序按 60 倍速把进度报上去（7 分钟的一节，几秒钟报完）。
  认没认不靠猜：日志里会把平台的回话原样写出来（accepted / rejected）。
  连续被拒 3 条就停下，并留下 伪心跳-样本.json。
  改完开关要重跑一次驱动器才生效（主菜单 2 停 → 1 开始）。

答题助手设置（按 4 进去以后）
  1   不做题
        只放视频、只翻节，测验一概不碰。
        ← 「我只想看视频」就选这个
  2   记下题，不问 AI
        把题目抄进 章节测验记录.txt，但不花钱、不给答案。
  3   记下题 + 问 AI
        抄下来并让模型给答案和理由，然后把答案填进页面。
        ← 「我要自动填答案」就选这个
  4   输入 / 更换 API key
  5   换模型
  6   测验停 / 测验不停
        测验停：一碰到测验就停下等你。测验不停：记下题目继续往后跑。
  7   每章最多问几题
  8   看当前配置
  9   测试 key 能不能用（真的发一次请求，要花钱，几分钱）
 10   清除 key
 11   读题方式
 12   自动填答案（只填，不交）

三个高频问题的答案：
  只想让它放视频            → 设置里按 1
  要它填答案                → 设置里按 3，并且 12 要开
  不要它填，只想自己看答案  → 设置里按 3，把 12 关掉


------------------------------------------------------------
  四、它到底怎么读题的（这一段决定你要花多少钱）
------------------------------------------------------------

学习通有「字体反爬」：题目的文字在网页源码里存的是**替身字**，
屏幕上看着是正常汉字，程序读出来是乱码。
（比如页面上显示"从法律"，源码里存的是"庘庝律"。）

两种对付办法：
  · 用一张「字体对照表」把替身字换回真字 —— 快、免费、零误差。
    但平台一换字体，表就作废。这个工具带了表，
    检测到对不上时会自动改走下面那条路。
  · **截图 + 让 AI 看图抄题** —— 不看字体，对方怎么换都拦不住。
    代价是慢一点、每次要花 API 费用。**目前主要靠这条。**

截图这条路做过两次改良，值得知道：
  · 它不再拍整屏，而是**算出每道题的坐标，只拍那一块**。
    所以图上字大、清晰，模型认得更准；也不会再拍到旁边别的卡片。
  · 截图之前它会检查浏览器窗口 —— 如果你把 Edge 窗口拖到屏幕边角、
    压得很扁，它会先把窗口恢复成正常大小再拍。
    （以前这里会拍出一条空白带，模型只能说"图片里没有题目"。）

答题走的是 DeepSeek，**开着思考模式**（抄录用 high 档，答题用 max 档）。
这是拿钱换准确率：思维链本身也算输出 token，会明显推高用量。
省钱就把「每章最多问几题」调小（菜单 7），或者干脆用模式 2 只记不答。


------------------------------------------------------------
  五、运行期间会生成哪些文件
------------------------------------------------------------

这几个是**专门给你看的**：

  本次运行-题目计数.txt
      每一章一行小结：遇到几道题、填上几道、欠几道。
      文件末尾还有一份总账。**想看总体情况只看这一个文件就行。**

  本次运行-没做的题.txt
      没填上的题，逐条记着题干和原因（为什么没填上）。
      回头补的时候照这个清单来。

  章节测验记录.txt
      所有抄下来的题目原文 + AI 给的答案和理由。
      这个文件是累积的，不会清空。

  待办-未完成任务点.txt
      被跳过的章节清单（这章有任务点没做完，程序按你的设置跳过去了）。
      是给你回头补的清单，不是错误日志。

  运行日志.txt
      最详细的实时日志，每一行都写清了它当时在干什么、为什么这么干。
      控制台按 3 就是盯着这个文件。太长了可以整个删掉，会重新建。

  运行中.pid
      当前驱动器的进程号，给「停止」用的。不用管它。

上面这几个「本次运行-*」文件，**每次启动驱动器时会重写**，
所以它们只反映这一次运行的情况。


------------------------------------------------------------
  六、最容易搞糊涂的六个地方
------------------------------------------------------------

(1) 为什么它不关掉我的浏览器窗口？
    启动时会先探一下 9222 端口。端口在，说明浏览器已经是可调试的，
    那就一个窗口都不关，直接用。
    只有端口不在、确实需要重启浏览器时，才会关 Edge 并重开
    （而这一步会让你按任意键确认，不确认就不动）。
    所以正常情况你正在看的网页、正在聊的窗口都活着。

    反面情况：Chromium 136 以后，默认配置目录下调试端口会被禁掉。
    这个工具用的是单独的配置目录
        %LOCALAPPDATA%\Microsoft\Edge\User
    它有自己的登录态 —— 你第一次跑的时候要在那个窗口里自己登录一次
    学习通，之后就一直记住了。

(2) 日志半天不动，是卡住了吗？
    多半不是。三种情况都会让日志看起来停住：
      · 答题用了 max 档思考，做一套题想几十秒很正常。
        想完之后它会把「抄录」和「答案」两段一次性全吐出来。
      · 刚切到一个新章节时有 30 秒宽限期。三层 iframe 还没渲染完，
        这段时间它故意不翻节，也不写日志。
      · 平台有个怪脾气：第一次点「下一节」经常没反应，得点第二次
        才弹窗。所以它会等 20 秒再点一次，日志上看着就是「没动静」。
    真卡住的标志是：超过两三分钟一行新的都没有，而且
    运行日志.txt 的修改时间也不再变。
    这时按 3 看一眼，再去任务管理器看有没有 node.exe。
    （现在它每轮都会检查自己跟浏览器的连接；连接断了会自己重连，
      不用你管。）

(3) 弹窗「当前章节还有任务点未完成，是否去完成？」是什么？
    平台的拦路弹窗，意思是有任务点没做完，不让你直接翻过去。
    程序会自己处理：优先点弹窗里的「下一节」直接往前走
    （这一章会被跳过），点不到就点「关闭」。
    以前这里点不动会让整个程序退出 —— 已经改了，现在会多试很多轮。

(4) 那 待办-未完成任务点.txt 里为什么会多出东西？
    被跳过的章会记一笔，记的是「这章有任务点没完成」。
    这是给你回头补的清单，不是错误日志。

(5) 它以前为什么会自己停下来？
    老版本的设计是「一遇到搞不定的事就退出」：弹窗连点 3 次不动、
    翻节连失败 3 次、弹窗反复出现 —— 任何一个都会让进程结束。
    现在两道保险：
      · 退出闸门放宽了（弹窗要连续 25 轮处理不掉才停，
        翻节要连续 40 次失败才停，之前都是 3 次）
      · 外面套了一层「自愈外套」（_内部\驱动器循环.cmd）：
        驱动器不管因为什么退出，15 秒后自动重新拉起来，最多 60 次。
        日志里会出现「驱动器退出了（第 N 次）。15 秒后自动重新拉起」，
        看到这行说明外套在干活，不用管。
    要彻底停就回控制台按 2 —— 它会先立一个「停止标记」再杀进程，
    外套看到标记就不会再自动重来。

(6) 「暂时保存」和「提交」的区别
    暂时保存（noSubmit）＝ 存草稿，题目还留着，可以继续改。
    提交 ＝ 交卷，交了就定了，**任务点也才会变成已完成**。
    程序只点前者。你自己的答案检查完了，再自己按提交。

(7) 有个提示说"模型没有返回正文"
    那是模型的**思考过程把输出额度用光了**，正文一个字都没剩。
    请求其实是成功的（所以不报错），但答案拿不到。
    偶尔碰到一次不用管；老是这样就把「每章最多问几题」调小一点。


------------------------------------------------------------
  七、花多少钱 / 答案准不准
------------------------------------------------------------

准不准：不知道。模型给的答案没有经过任何验证，
        记录文件的开头也写着这句话。请当成「草稿」看。

花钱：只有「问 AI」那一步花钱，其它全是本地操作。
      **这笔钱花在你自己的账户上** —— key 是你自己填的，
      走 DeepSeek 官方接口、按 token 计费，不经过作者。
      一次三题的小测验大致几分钱量级 ——
      注意这只是估算，程序没有记录用量，所以我给不出精确数字。
      省钱的两个开关：
        · 设成「只记下题，不问 AI」＝ 零成本
        · 把「每章最多问几题」调小（菜单 7）
        · 截到的图越小越省：它现在只拍每道题那一块，
          比以前的整屏图省很多。

      官方价格随时会变，以 https://api-docs.deepseek.com/zh-cn/quick_start/pricing  为准。
      注意 DeepSeek 有夜间优惠时段，同样的活晚上跑更便宜。


------------------------------------------------------------
  八、出问题了怎么办
------------------------------------------------------------

症状：双击 控制台.cmd 一闪就没了 / 提示无法加载脚本
  原因：PowerShell 执行策略
  动作：右键 → 用 PowerShell 运行一次这条命令：
        Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
        （问 Y）

症状：控制台说「没找到 node」或「node 版本太旧」
  原因：你拿的是精简版，或者系统里的 Node 太老
  动作：去 https://nodejs.org/ 下 LTS 版装一次，装完把黑窗口关掉、
        重新双击 控制台.cmd。完整版不会碰到这个问题（包里带了）。

症状：一直提示「等不到调试端口」
  原因：Edge 被别的程序拦住，或端口 9222 被占
  动作：关掉所有 Edge 窗口再点 1；还不行就重启电脑

症状：日志里一堆「找不到「下一节」按钮」
  原因：要么页面还在加载，要么这一章真到头了
  动作：不用管，它会自己重试（连续 40 次才停）

症状：日志里「平台弹窗还在，这一轮没找到可点的按钮」刷了 25 次然后停
  原因：弹窗上有程序认不出的按钮
  动作：你手动把那个弹窗点掉，再回控制台按 1

症状：报 401 / 402 / 429
  401 = key 不对；402 = 余额不足；429 = 请求太快
  动作：控制台 → 4 → 9 测一下 key

症状：页面突然跳回登录页
  原因：那个专用配置目录的登录态过期了
  动作：在它开的那个 Edge 窗口里重新登录一次

症状：日志里出现「截图抄录里一道题都没有」
  原因：多半是切标签栏的瞬间截图拍到了别的卡片
  动作：不用管 —— 它会自己重新打开测验栏、重拍一次。
        如果重拍还是不行，那一道会被记进「没做的题」，你手动补。

症状：题目填进去了，但选中的位置不对
  原因：题型识别错了（判断题和多选题长得像）
  动作：回控制台按 5 解码看看记录里 AI 是怎么判的

最重要的排查手段：控制台按 3 看日志。
日志里每一行都写清了它当时在干什么、为什么这么干。


------------------------------------------------------------
  九、文件夹里都是什么
------------------------------------------------------------

控制台.cmd              唯一的入口，双击它
学习通-CDP\             全部程序
  控制台.ps1            控制台界面
  driver.js             主驱动器：放视频、翻节、处理弹窗、滚文档
  答题助手.js           测验模块：读题、问 AI、填答案、暂时保存
  配置.js               命令行读写设置（控制台背后就是调它）
  解乱码.js             字体反加密的解码器
  diag.js               诊断工具：把页面结构全 dump 出来
  保持唤醒.ps1          运行期间申请不睡眠
  原理说明.txt          技术细节（三层 iframe、字体反爬、CDP 怎么用）
  node\node.exe         ← 包里自带的 Node（完整版才有），不用另外装
  我的课程.txt.示例     ← 改名去掉「.示例」就是真的配置文件
  答题设置.json.示例    同上；里面没有 key，key 要用控制台填
  我的课程.txt          开始时要打开哪些网页，一行一个，# 开头忽略
  答题设置.json         设置和 API key 存这（明文，别外传）
  本次运行-题目计数.txt  每章一道题的小结 + 总账  ← 看总体情况看这个
  本次运行-没做的题.txt  没填上的题，逐条带原因
  章节测验记录.txt      所有抄下来的题目和答案（累积）
  待办-未完成任务点.txt 被跳过的章节清单
  运行日志.txt          实时日志（会一直追加）
  运行中.pid            当前驱动器的进程号
  _内部\                开始 / 停止 / 看进度 / 设置 / 解乱码 / 驱动器循环
  _字体\                字体解码表（页面换了字体这张表就作废，
                        程序检测到不匹配会自动改用截图读题）


------------------------------------------------------------
  十、关掉 / 卸载
------------------------------------------------------------

停止：控制台按 2
      （它会问你要不要顺便关浏览器，默认不关）
卸载：删掉整个文件夹。
      另外可以顺手删掉 %LOCALAPPDATA%\Microsoft\Edge\User
      —— 那是它专用的浏览器配置目录，里面有你的登录态。
      不删也不影响什么，就是占地方。


------------------------------------------------------------
