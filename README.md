# xuexitong-helper

本机运行的**学习通课程助手**（正式版 · 2026-10-17）

## 这一版是什么

- 放视频、翻章节（遇到拦路弹窗自己处理）、把文档/PDF 滚到底；**不改播放倍速**，
  想更快靠"伪心跳"替播放器上报进度（默认关，主菜单按 8 开）。
- 测验：读题（替身字体本地解开，不用 AI）→ 需要时问模型 → 把答案填进页面 → 点「暂时保存」。
- 本地题库：题目自动入库，库里有答案的直接复用（0 次模型调用）；可按标签导出题库码。
- 启动器全部加了错误捕获：失败会停住并显示原因，不再"一闪就没"。
- 运行时加固：进程查询错误保真、单实例锁 fail-closed（防双开）、启动 40 秒总预算、
  临时目录三级回退（含"建文件被拒"判定——杀软放行建目录、拦 node 建文件时自动换下一级）。
- 自带**手动备用启动** `启动助手浏览器-9222.cmd`：自动拉起浏览器被安全软件拦掉时，
  双击它手动拉起助手浏览器，登录、切课，再启动控制台（控制台发现端口已通会跳过自动拉起）。

## 怎么开始

1. 下载 Releases 里的 **完整包**（`学习通助手-正式版-可分发-20261017.zip`，自带 node）
   或 **精简版**（需机器上有 Node.js ≥18）
2. 解压到**用户目录**（如桌面），清掉只读属性（微信/网盘传过来的包常带只读）
3. 双击 `学习通助手\学习通-CDP\控制台.cmd`
4. 在**助手自己开出来的那个 Edge** 里登录学习通，打开要跑的课程**学习页**（URL 里有 studentstudy）
5. 回控制台点 1（没有浏览器它自己开；已经开着就不重复启动）

详见包内的 `使用说明.txt` 与 `版本说明.txt`（版本说明里写了"拿到包之后重点测什么"）。

## 边界

- **绝不提交**：只填答案、只点「暂时保存」；提交按钮永远你自己按，代码里没有提交逻辑。
- 不写注册表、不改用户级环境变量；题库/记录/缓存全部留在程序目录里。
- 这个仓库里**没有**任何用户数据（题库、记录、缓存、日志都不在）——
  分发包里也一样，打包时自动拦掉了。
