# xuexitong-helper

本机运行的学习通课程助手（**0.2 修复版**）

## 这一版是什么

把「本地题库」做成了完整的一环：替身字体不用 AI 就能解开、题目自动进本地库、
库里有的题下次直接复用答案（0 次模型调用）；另外可以按标签把题库导成**可导入的题库码**。

## 怎么开始

1. 下载 Releases 里的 **完整包**（`学习通助手-0.2修复版-可分发-20261012.zip`，自带 node）
2. 解压，双击 `学习通助手\学习通-CDP\_内部\开始.cmd`
3. 在**助手自己开出来的那个 Edge** 里登录学习通，打开你要跑的课程**学习页**（URL 里有 studentstudy）
4. 回到控制台页面（`http://127.0.0.1:8898/`），点【开浏览器并开始】

详见包内的 `使用说明.txt` 与 `版本说明.txt`（版本说明里写了"拿到包之后重点测什么"）。

## 边界

- **绝不提交**：只填答案、只点「暂时保存」，提交按钮永远你自己按；代码里没有提交逻辑。
- 不写注册表、不改用户级环境变量；题库/记录/缓存全部留在程序目录里。
- 这个仓库里**没有**任何用户数据（题库、记录、缓存、日志都不在）——
  分发包里也一样，打包时自动拦掉了。
